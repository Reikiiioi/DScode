## 📖 О проекте

**DeepSeek Code** — это легковесный терминальный AI-ассистент, работающий напрямую с бэкендом `chat.deepseek.com`. Разработан специально для разработчиков, предпочитающих работать в командной строке. Предоставляет современный консольный интерфейс (TUI) с живым стримингом токенов, подсветкой синтаксиса кода, поддержкой веб-поиска и автоматическим решением криптографических проверок Proof-of-Work (PoW).

Для работы **не требуются** платные API-ключи, сторонние прокси-серверы или запуск локального веб-сервера (`без localhost`).

## ✨ Основные возможности

- ⚡ **Плавный потоковый вывод (Streaming)**: живой рендеринг ответа со скоростью 10 кадров в секунду (FPS) без задержек.
- 🎨 **Продвинутый рендеринг Markdown в терминале**:
  - Подсветка синтаксиса кода на базе темы `monokai`.
  - Интерактивные чек-листы (`- [ ]` $\rightarrow$ `☐`, `- [x]` $\rightarrow$ `☑`).
  - Математические формулы LaTeX (`$$...$$`) автоматически форматируются в аккуратные блоки кода.
  - GitHub-стиль уведомлений (`[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`) с эмодзи-индикаторами.
- 🌐 **Встроенный веб-поиск**: команда `/search <запрос>` активирует поиск в интернете в реальном времени со статусом (`Found N web pages`) и выводом источников.
- 🛡️ **Автоматический обход Proof-of-Work (PoW)**:
  - Автоматически скачивает официальный файл `sha3_wasm_bg.wasm` с CDN DeepSeek при первом запуске.
  - Мгновенно решает криптографическую задачу внутри Python через `wasmtime`.
  - Предусмотрен плавный откат (fallback) на системный `Node.js`, если `wasmtime` не установлен.
- 🧹 **Чистый аккаунт без мусора**: сессии создаются «на лету» и автоматически удаляются в фоновом потоке, не засоряя историю чатов в веб-интерфейсе `chat.deepseek.com`.
- ⏱️ **Метрики времени и задержки**: подробная телеметрия каждого запроса (`⏱ Sent: 21:04:12 │ Received: 21:04:15 │ Duration: 2.84s`).
- 🖥️ **Кроссплатформенность**: полная поддержка цветов ANSI и кодировки UTF-8 в Windows (автоматический Virtual Terminal Mode), macOS и Linux.

## 🚀 Быстрый старт

### 1. Системные требования

- **Python 3.8+**
- **Движок WebAssembly** (один из вариантов):
  - `wasmtime` (рекомендуется, ставится через pip)
  - ИЛИ установленный в системе **Node.js** (для резервного вычисления)

### 2. Установка

Скопируйте файлы проекта в рабочую директорию и установите необходимые зависимости:

```bash
pip install requests rich wasmtime
```

*(Если библиотека `wasmtime` не установлена, убедитесь, что команда `node` доступна в системной переменной `PATH`.)*

### 3. Авторизация (Получение токена)

DeepSeek Code использует ваш пользовательский токен с сайта `chat.deepseek.com`.

#### Как получить токен:
1. Откройте [chat.deepseek.com](https://chat.deepseek.com) в браузере и войдите в свой аккаунт.
2. Нажмите клавишу `F12` (или правой кнопкой мыши $\rightarrow$ **Просмотреть код**), чтобы открыть инструменты разработчика.
3. Перейдите во вкладку **Application** (или **Хранилище**) $\rightarrow$ **Local Storage** $\rightarrow$ `https://chat.deepseek.com`.
4. Найдите параметр с именем `userToken` (либо во вкладке **Network** найдите любой запрос к API и скопируйте значение из заголовка `Authorization: Bearer <токен>`).
5. Скопируйте строку токена.

#### Установка токена в систему:

Вы можете передать токен через переменную окружения или прописать напрямую в коде:

**Вариант А: Через переменную окружения (Рекомендуется)**

- **Linux / macOS:**
  ```bash
  export DEEPSEEK_TOKEN="ваш_токен_здесь"
  ```
- **Windows (PowerShell):**
  ```powershell
  $env:DEEPSEEK_TOKEN="ваш_токен_здесь"
  ```
- **Windows (Командная строка CMD):**
  ```cmd
  set DEEPSEEK_TOKEN=ваш_токен_здесь
  ```

**Вариант Б: Напрямую в скрипте**

Откройте `DeepSeekCode.py` и укажите ваш токен в переменной:
```python
DEFAULT_TOKEN = "ваш_токен_здесь"
```

## 🛠️ Архитектура и принцип работы

```
┌────────────────────────────┐
│      Терминал юзера        │
│    (Промпты / Команды)     │
└─────────────┬──────────────┘
              │
              ▼
┌────────────────────────────────────────────────────────┐
│                   DeepSeekCode.py                      │
│                                                        │
│  1. Запрос PoW-задачи     ──► /api/v0/chat/create_pow  │
│  2. Решение через WASM    ──► wasmtime / node          │
│  3. Создание сессии       ──► /api/v0/chat_session/create│
│  4. Потоковый ответ (SSE) ──► /api/v0/chat/completion  │
│  5. Фоновое удаление      ──► /api/v0/chat_session/delete
└─────────────┬──────────────────────────────────────────┘
              │
              ▼
┌────────────────────────────┐
│    Rich Markdown Stream    │
│  (Живой рендеринг 10 FPS)  │
└────────────────────────────┘
```

1. **Решение PoW (Proof-of-Work)**: перед каждым запросом DeepSeek генерирует задачу сложности. Скрипт использует модуль `sha3_wasm_bg.wasm` для вычисления ответа и передает результат в заголовке `x-ds-pow-response`.
2. **Контекст диалога**: скрипт сохраняет до 10 последних сообщений диалога (`history[-10:]`), сохраняя контекст общения.
3. **Очистка сессий**: после генерации ответа временная сессия асинхронно удаляется с серверов DeepSeek, предотвращая накопление сотен пустых диалогов в веб-версии.

## ⚙️ Тонкая настройка

В файле `DeepSeekCode.py` доступны параметры для кастомизации:

- **`SYSTEM_PROMPT`**: системная инструкция модели. Позволяет задать поведение, язык или специализацию ассистента.
- **Глубина контекста**: по умолчанию передаются последние 10 реплик (`history[-10:]`).
- **Тема подсветки кода**: по умолчанию используется тема `monokai`, настраивается в вызове `Markdown(..., code_theme="...")`.

## ❓ Решение проблем

- **`RuntimeError: PoW status=...`**: убедитесь, что библиотека `wasmtime` установлена или `node` доступен в системных путях.
- **`HTTP 401: Unauthorized`**: срок действия вашего токена истек или он указан неверно. Обновите токен из cookies/хранилища браузера.
- **Проблемы с отображением спецсимволов в Windows**: скрипт автоматически активирует режим Virtual Terminal. Если символы отображаются некорректно в классическом CMD, используйте современный Windows Terminal или шрифты с поддержкой UTF-8 (Cascadia Code, Consolas, JetBrains Mono).
